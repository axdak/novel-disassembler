# 小说/故事创作系统四维度框架规范

> 本规范面向"事前创作规划"，定义世界观(W)/剧情线(P)/大纲(O)/细纲(D) 四个维度，用于在正式动笔前搭建可追溯、可联动、可校验的故事骨架。
>
> 与拆书向的 `analysis_four_dimensions.md` 互补：拆书向是"从已有原文反推"，本规范是"从无到有规划"。

## 0. 维度关系总览

四维度不是并列，而是金字塔：

```text
世界观 W   —— 稳态底层（变更代价最高）
   ↓ 约束
剧情线 P   —— 时间脉络层
   ↓ 落点
大纲 O     —— 结构骨架层（按卷切分）
   ↓ 展开
细纲 D     —— 执行颗粒层（章/场景级）
```

上层变更必须向下传播；下层执行不得违背上层约束。

## 1. 世界观维度（W）

### 1.1 八要素架构表

| 编号 | 要素 | 说明 | 关键字段 | 与其他要素的关联 |
|---|---|---|---|---|
| W-ERA | 时代背景 | 故事发生的时代定位 | 时代名、技术水平、社会形态、典型矛盾 | 决定 W-SYSTEM 的合理性、W-FACTION 的组织形式 |
| W-GEO | 地理环境 | 世界地图与核心区域 | 大陆/区域、地形、气候、资源分布 | 支撑 W-FACTION 的座落、W-RACE 的栖息地 |
| W-SOC | 社会制度 | 政治/经济/法律/阶层 | 政体、阶级、流通货币、律法框架 | 决定 W-FACTION 的合法性来源、W-RACE 的社会地位 |
| W-FACTION | 势力格局 | 国家/宗门/帮派/组织 | 名称、类型、实力等级、目标、敌对关系 | 依托 W-GEO 立足，受 W-SOC 规范，是 P-MAIN 的主要承载者 |
| W-SYSTEM | 力量体系/魔法系统 | 战力来源与规则 | 能量来源、修炼路径、等级划分、代价/限制 | 必须有代价闭环，影响 W-FACTION 实力对比 |
| W-RACE | 种族设定 | 智慧种族特征 | 种族名、生理特征、寿命、天赋、文化 | 栖息于 W-GEO，受 W-SOC 待遇差异，可能拥有专属 W-SYSTEM 分支 |
| W-HISTORY | 历史纪年 | 大事年表与纪年法 | 纪年法、分期、重大事件、遗留影响 | 为 W-FACTION 关系、W-SYSTEM 源流、伏笔 P-FORESHADOW 提供依据 |
| W-RULE | 世界规则 | 物理法则/禁忌/天命 | 基础法则、特殊规则、禁忌、例外条件 | 全局约束，任何 P/O/D 不得违背 |

### 1.2 世界观要素 JSON 落地结构（示例）

```json
{
  "编号": "W-FACTION-003",
  "类型": "势力格局",
  "名称": "玄天宗",
  "详细介绍": "",
  "属性": {
    "类型": "宗门",
    "实力等级": "一流",
    "座落地点": "W-GEO-005:青云山脉",
    "核心目标": "",
    "敌对势力": ["W-FACTION-007:血煞门"],
    "盟友势力": ["W-FACTION-002:皇朝"]
  },
  "自洽检查": {
    "地理支撑": "W-GEO-005 是否能容纳该势力规模",
    "制度匹配": "W-SOC 是否允许该势力存在",
    "力量来源": "W-SYSTEM 是否提供该势力的战力依据"
  },
  "关联剧情线": ["P-MAIN-001", "P-SUB-003"],
  "首次出场卷": "O-VOL-01",
  "对齐引用": []
}
```

### 1.3 世界观自洽性检查清单（7 项）

1. W-SYSTEM 是否存在代价闭环（获得力量必须有代价）。
2. W-FACTION 之间是否形成完整的敌友中性关系闭环，不存在孤立势力。
3. W-GEO 是否能支撑所有 W-FACTION 的座落与资源需求。
4. W-SOC 是否与 W-ERA、W-FACTION 的组织形式匹配。
5. W-HISTORY 中的重大事件是否在当前 W-FACTION/W-RACE 上留有痕迹。
6. W-RULE 是否存在自相矛盾（如既说"灵魂不可逆"又出现复活术）。
7. 任何 W 要素是否孤立存在，未与任何 P/O/D 关联。

## 2. 剧情线维度（P）

### 2.1 剧情线分类与优先级

| 编号前缀 | 类型 | 优先级 | 推进节奏 | 典型承载 |
|---|---|---|---|---|
| P-MAIN | 主线剧情 | P0 | 全程推进，每卷必有进展 | 核心冲突、终极目标 |
| P-SUB | 支线剧情 | P1 | 间歇推进，可跨卷 | 副本、配角故事、世界观展开 |
| P-FORESHADOW | 暗线/伏笔线 | P1 | 长间隔，铺设—暗示—回收三段式 | 真相揭示、反转铺垫 |
| P-GROWTH | 角色成长线 | P0 | 与主角节奏同步 | 心境突破、能力进阶、认知转变 |
| P-EMOTION | 情感线 | P1-P2 | 慢热，节点式推进 | 爱情、亲情、师徒、兄弟 |

### 2.2 单条剧情线登记表

| 字段 | 说明 |
|---|---|
| 编号 | P-MAIN-001 |
| 名称 | 主线·（一句话主题） |
| 类型 | 主线/支线/暗线/成长/情感 |
| 优先级 | P0/P1/P2 |
| 核心目标 | 这条线要解决什么问题 |
| 起点 | 第几卷/第几章，触发事件 |
| 承节点 | 推进过程中的关键节点 |
| 转节点 | 方向转变或重大反转 |
| 合节点 | 收束或阶段性收束 |
| 交汇点 | 与其他 P 线交叉的位置（填编号） |
| 推进节奏 | 密集/间歇/长间隔 |
| 涉及角色 | 对应 W-FACTION 角色或独立角色编号 |
| 涉及势力 | W-FACTION 编号列表 |
| 当前状态 | 规划中/进行中/已收束/已弃用 |
| 对齐引用 | 拆书态 `事件:名称` / `线索:名称` |

### 2.3 伏笔线三段式管理表

| 编号 | 伏笔内容 | 铺设节点 | 暗示节点（可多次） | 回收节点 | 状态 |
|---|---|---|---|---|---|
| P-FORESHADOW-001 | | O-VOL-01/D-CH-003 | O-VOL-02/D-CH-045 | O-VOL-04/D-CH-120 | 已回收/待回收/已弃用 |

### 2.4 剧情线交汇点矩阵

| 交汇点编号 | 发生位置 | 涉及剧情线 | 交汇类型 | 交汇效果 |
|---|---|---|---|---|
| X-001 | O-VOL-02 高潮 | P-MAIN-001 × P-FORESHADOW-003 | 主线触发伏笔回收 | 真相揭穿，主线转向 |

交汇类型枚举：触发/阻碍/揭示/合流/分裂/对照。

## 5. 四维度联动规则

### 5.1 统一引用格式

```text
维度:编号:名称
```

示例：

```text
W-FACTION-003:玄天宗
P-MAIN-001:主线·血契觉醒
O-VOL-02:北境风云
D-CH-014-S02:第14章场景2
X-001:伏笔回收交汇点
```

### 5.2 引用方向规则

- W → P：W 要素可被多条 P 引用（一对多）。
- P → O：一条 P 线的节点必须落到某个 O-VOL。
- O → D：一个 O-VOL 展开为多个 D-CH。
- D → P：每个 D-CH 必须标注它推进的 P 编号。
- D ↔ W：D 中出现的 W 要素必须用引用，不得重述。

### 5.3 变更传播规则

| 变更源 | 影响范围 | 必须重审 |
|---|---|---|
| W 要素变更 | 全量 | 所有引用该 W 的 P/O/D |
| P 线节点变更 | 该 P 及其交汇点 | 相关 O-VOL、相关 D-CH |
| O-VOL 调整 | 该卷 | 该卷下所有 D-CH |
| D-CH 调整 | 局部 | 仅该章涉及的 P 节点状态 |

### 5.4 联动回溯检查清单（6 项）

1. 每个 W 要素至少被 1 条 P 引用，否则标记"孤立设定"。
2. 每条 P-MAIN 必须有起点、承、转、合四节点，缺一标记"断裂"。
3. 每个伏笔必须有铺设与回收节点，只有铺设标记"待回收"。
4. 每个 O-VOL 必须有至少 1 个关键转折和 1 个高潮，缺一标记"结构薄弱"。
5. 每个 D-CH 必须标注推进的 P 编号，无标注标记"游离章节"。
6. W-RULE 不得被任何 D-CH 违背，违背标记"违规"。

## 6. 与拆书体系的双向对齐

本框架可与拆书态 `故事结构.json` 通过 `对齐引用` 字段打通，支持三种协作模式：

| 模式 | 流程 | 适用场景 |
|---|---|---|
| 先创后拆 | W/P/O/D 规划完成 → 写作 → 完稿后拆书校验 | 全新创作 |
| 先拆后创 | 拆书已有作品 → 反推 W/P/O/D → 借鉴续写/改编 | 续作、同人、改编 |
| 边创边拆 | 写一段拆一段，创与拆互相校验 | 长篇连载、质量敏感项目 |

### 6.1 对齐字段映射

| 创作态 | 拆书态 |
|---|---|
| W-FACTION | 阵营:名称 |
| W-GEO | 地点:名称 |
| W-RACE/W-SOC 中的人物 | 角色:名称 |
| P-MAIN/P-SUB 的节点 | 事件:名称 |
| P-FORESHADOW | 线索:名称 |
| W-SYSTEM 中的道具 | 物品:名称 |

### 6.2 对齐引用字段示例

```json
{
  "编号": "W-FACTION-003",
  "名称": "玄天宗",
  "对齐引用": ["阵营:玄天宗"]
}
```

## 7. 质量门槛

| 阶段 | 必须完成 |
|---|---|
| 立项 | W 八要素至少完成 6 项；P-MAIN 至少 1 条且有四节点 |
| 开写前 | W 八要素全部完成；P 全部规划；O 全卷表完成；D 至少完成第一卷 |
| 写作中 | 每写完一卷，刷新该卷 D 与相关 P 状态；伏笔状态及时更新 |
| 完稿后 | 全部 D 完成；联动回溯检查 6 项全部通过；与拆书态对齐引用全部填充 |
